## Commands

```
python3 -m pcbenv.generate --out tasks --start-seed 0 --count 820 --holdout-frac 0.2 --workers 4
python3 -m pcbenv.generate --pack tasks --dist dist
python3 -m pcbenv.generate --out tasks/refresh-100000 --start-seed 100000 --count 120 --holdout-frac 0.2 --workers 4 --dedupe-against tasks/manifest.jsonl
python3 -m pytest -q tests/test_faults.py tests/test_generate.py
```

Generation is deterministic: the same arguments give the same task ids and byte-identical files (tested in `tests/test_generate.py::test_generation_deterministic`, 4 vs 2 workers).
