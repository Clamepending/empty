Generated by `python3 -m pcbenv.report_v2` from the generators' own statistics (`generation_stats.json`) and public manifests. Nothing here is hand-edited.

## Commands

```
python3 -c "from pcbenv.taskids import load_secret; load_secret('tasks/.secret', create=True)"   # once; keep private
python3 -m pcbenv.generate --tier normal --out tasks/v2/normal --holdout-out tasks/v2/normal_holdout --start 0 --count 822 --workers 4 --secret tasks/.secret --private tasks/private/normal.jsonl
python3 -m pcbenv.generate --tier hard --out tasks/v2/hard --holdout-out tasks/v2/hard_holdout --start 0 --count 640 --workers 4 --secret tasks/.secret --private tasks/private/hard.jsonl
python3 -m pcbenv.layout_rules --sweep 50 --out reports/v2/layout_rules_sweep.txt
python3 -m pcbenv.generate --tier hard_layout --out tasks/v2/hard_layout --holdout-out tasks/v2/hard_layout_holdout --start 0 --count 205 --workers 4 --secret tasks/.secret --private tasks/private/hard_layout.jsonl
python3 -m pcbenv.generate --combine tasks/v2/normal tasks/v2/normal_holdout tasks/v2/hard tasks/v2/hard_holdout tasks/v2/hard_layout tasks/v2/hard_layout_holdout --manifest tasks/manifest.jsonl
python3 -m pcbenv.generate --pack tasks/v2 --dist dist
python3 -m pcbenv.generate --tier normal --out tasks/refresh-v2/normal --start 100000 --count 120 --holdout-frac 0 --workers 4 --secret tasks/.secret --dedupe-against tasks/manifest.jsonl --private tasks/private/refresh_normal.jsonl
python3 -m pcbenv.generate --tier hard --out tasks/refresh-v2/hard --start 100000 --count 170 --holdout-frac 0 --workers 4 --secret tasks/.secret --dedupe-against tasks/manifest.jsonl --private tasks/private/refresh_hard.jsonl
python3 -m pcbenv.report_v2 --commands reports/v2/generation_commands.txt --out reports/v2_generation.md
python3 qa/spot_check_v2.py --per-tier 20 --seed 2026 > reports/v2/spot_check.txt
```

Task ids are opaque (`pcbr2-<tier>-<hmac8>`) and generator seeds are HMAC(secret, index) (RT37, `pcbenv/taskids.py`). The secret is `tasks/.secret` (git-ignored, never published); seeds live only in `hidden/meta.json` and the private manifests `tasks/private/*.jsonl` (git-ignored). Public manifests (`tasks/manifest.jsonl`, one per split dir, inside the tarballs) carry family / fault metadata but no seeds. Byte-identical regeneration needs the same secret; `--secret default` is the documented public secret for reproducibility runs (tests use it).
